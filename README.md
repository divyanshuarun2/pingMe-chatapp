# pingMe-chatapp
A Full stack chat and mini shop application, built with Java Springboot (backend) and React (Frontend), featuring real-time messaging, user authentication, and deployment ready architecture
# pingMe is a real time  chat application with a mini e-consumer mosule,designed to showcase full-stack development skills:
1. Backend: Java 17, SpringBoot, Spring Security, JPA, Web Socket
2. Frontend: React.js
3. Database: MySQL
4. Messaging & Queue: RabbitMQ/ Kafka (for async messages)
5. Deployment: Docker, CI/CD with Github actions, AWS EC2/S3
# Features
1. User sognup/login with JWT authentication
2. Real-time messaging(text,image,media)
3. mini-shop with payment gateway integration
4. Scalable architecture with CI/CD pipelines

# Learning Focus
Full stack development, system design,cloud deployment, security and preparation for future web3 integration.
